# 99乘法表游戏

一个简单有趣的数学练习游戏，帮助小朋友练习乘法和除法。

## 功能特点

- 🎯 **乘法练习**：1×1 到 9×9 的乘法题目（不包含 1）
- 🔢 **除法练习**：对应的除法题目
- 🎲 **混合模式**：乘法和除法随机混合
- 📊 **多种题量**：支持 10、20、50、100 题
- ⚡ **即时反馈**：答对/答错音效提示，实时显示得分和正确率
- 📱 **响应式设计**：适配桌面和移动设备
- 🔄 **重新开始**：支持快速重新开始游戏

## 使用方法

直接在浏览器中打开 `index.html` 即可开始游戏。

1. 选择题目类型（乘法/除法/混合）
2. 选择题目数量
3. 点击答案进行答题
4. 查看最终成绩

## 技术栈

- HTML5
- CSS3
- JavaScript (原生)
- Jest + fast-check (测试)
- Netlify (部署)

## 本地开发

### 安装依赖

```bash
npm install
```

### 运行测试

```bash
npm test
```

### 本地服务器

```bash
npm run serve
```

然后在浏览器中访问 `http://localhost:8000`

## 部署

已配置 Netlify 自动部署，push 到 main 分支后会自动部署。

## 游戏规则

1. 选择题目类型（乘法/除法/混合）
2. 选择题目数量（10、20、50、100题）
3. 从四个选项中选择正确答案
4. 实时查看得分和正确率
5. 游戏结束后查看详细统计（得分、正确率、答对/答错题数）

## 开发

### 添加新功能

1. 在相应的 JavaScript 类中添加功能
2. 编写对应的单元测试
3. 更新 UI 渲染逻辑（如需要）
4. 运行测试确保功能正常
